# Stage 6 补充 + Stage 7：latent 距离能不能当规划代价（离线，不用模拟器）

第 1–3 节的模型：xysc、fs8、H=3，不加 B1（`s4_xysc_fs8_h3`）和 B1 λ=1（`s5inv_xysc_fs8_h3_w1`），各 3 个 seed，第 10 个 epoch，val 集（7 个场景）。完整表格：[stage7_goal.md](stage7_goal.md)、[../stage6/stage6_epochs.md](../stage6/stage6_epochs.md)。代码：[eval_goal.py](https://github.com/fanxinyusarah/lewm-navigation-capstone/blob/080e49752c12f5784f67014c0105b7717269a831/yf/nav/eval_goal.py)、[summarize_goal.py](https://github.com/fanxinyusarah/lewm-navigation-capstone/blob/080e49752c12f5784f67014c0105b7717269a831/yf/nav/summarize_goal.py)。

## 1. 归一化 MSE：B1 并没有让预测更准

`nmse` = 预测 MSE / 目标 latent 的方差（与 latent 尺度无关；1 表示等于直接预测均值）。

| val，epoch 10 | 不加 B1 | B1 |
|---|---|---|
| 模型 / copy-last，k=1（报告里用的指标） | 0.871 | 0.614 |
| nmse，k=1 | **0.076** | 0.097 |
| copy-last 的 nmse，k=1 | 0.087 | 0.158 |
| nmse，k=8 | 0.890 | 0.920 |

B1 的比值改善主要来自分母：B1 让相邻帧的 latent 拉开了，copy-last 变难。按与尺度无关的口径看，B1 的预测误差略高。k=8（约 2.4 m）时两者都接近 1，多步预测基本没有信息量。

## 2. latent 距离与几何距离（Part A）

同一条轨迹内，固定一个目标帧，其他帧到目标的 latent 距离与真实平面距离的 Spearman ρ（对目标取平均）：

| | 不加 B1 | B1 |
|---|---|---|
| ρ（latent MSE，平面距离） | **0.70** | 0.64 |
| ρ（latent MSE，朝向差） | 0.41 | **0.51** |

两者的 latent 距离都随真实距离单调增加，可以作为规划代价的基础。B1 更多编码了朝向。

## 3. 多步候选动作排序（Part B）

每个 clip 用真实的第 t+k 帧作为目标图，24 条候选：真实的未来动作 + 15 条其他 clip 的动作 + 8 条结构化的“近似”动作（直行、±0.1/0.2/0.35 rad 每步的弧线、左右镜像）。模型 rollout 后按 d(ẑ_k, z_goal) 打分。

“选中误差”：在非真实候选里，模型选中的那条按指令位姿算出的终点离真实终点的距离。

| k | 指标 | 不加 B1 | B1 | 随机 | 最优 |
|---|---|---|---|---|---|
| 1 | top-1 选中真实序列（随机 0.042） | 0.057 | **0.230** | | |
| 2 | 选中误差 [m] | 0.148 | **0.092** | 0.145 | 0.031 |
| 4 | 选中误差 [m] | 0.434 | **0.283** | 0.431 | 0.076 |
| 8 | 选中误差 [m] | 1.409 | **1.003** | 1.234 | 0.189 |

（score = latent MSE；用 cosine 结果相近，B1 在 k ≥ 4 时 cosine 稍好。std 很小，见完整表格。）

- **不加 B1 的模型选动作和随机差不多**，k=8 时比随机还差。
- **B1 在 k=2–4 时比随机少 35–37% 的误差**，大约补上了“随机”与“最优”差距的 40–45%；k=8 时优势缩小。

## 4. 扩展：不同动作表示、不同 λ（30 个 checkpoint）

都是 fs8、H=3、第 10 个 epoch；score = latent MSE；“选中误差”含义同上，随机选的误差 k=2 / 4 / 8 分别为 0.145 / 0.431 / 1.234 m。离散表示（disc、dbin）下很多候选编码后和真实动作完全相同，top-1 只统计至少有一个不同候选的 clip，随机水平按实际候选数计算（括号内）。

|---|---|---|---|---|---|

- **B1 的作用在所有表示上都成立**：不加 B1 时，所有表示选动作都和随机一样；加了 B1 后，连续表示（xy / xyt / xysc）和 dbin 都明显好于随机。
- **离散动作（disc）会丢信息**：disc 的 top-1 看起来高，是因为它的候选只有“前进 / 左转 / 右转”几类，区分起来容易；但选中误差几乎和随机一样（加 B1 后 k=2 为 0.128 m，随机 0.145 m），说明它分不清转多少角度，不适合精细的规划。
- **λ 有一个权衡**：λ 越大，模型越能区分动作（选中误差在 λ=1–3 时最低），但 latent 距离和真实距离的相关性越低（0.70 → 0.59），也就是作为“距离尺子”越不准。λ=1 是比较平衡的选择，k=8 时也最好。
- xyt 和 xysc 基本没有差别；xy 没有转角信息，比它们略差。

## 结论与局限

- B1 没有让预测更准，但让模型能区分动作，而这正是规划需要的能力。
- 规划 horizon 建议取 2–4 步（约 0.6–1.2 m），配合 MPC 重规划。
- 局限：非真实候选只有**指令位姿**，没有真实画面，也没有碰撞判断，所以这里检验的是“位姿空间”里的排序。真实环境里的效果要靠模拟器分支实验（4b）和闭环（5）检验，这需要可用的场景网格和 habitat 环境。
